Send requests. Skip the Electron.

Floki is a fast native API client for Linux and Windows. Built with Rust and GPUI and rendered on the GPU. Work locally without an account, or sign in to share workspaces with your team.

Everything a request needs

A native client that opens in a blink, speaks the protocols you use, and keeps your data on your machine until you choose to share it.

  • Native and fast

    Rust and GPUI, GPU-rendered, no Electron. Runs on Linux and Windows.

  • Postman-compatible

    Import Postman collections (v2.0 and v2.1) and environments. Export collections in Postman v2.1 format.

  • Requests, fully equipped

    Params, headers and bodies: form-data with files, x-www-form-urlencoded, raw JSON, XML, HTML, Text or JS with Beautify, GraphQL, and binary.

  • Auth built in

    Basic, Bearer, Digest, OAuth 2.0 (client credentials and password), AWS Signature v4 and API key. Proxy and client certificates too.

  • More than REST

    WebSocket, Socket.IO, and gRPC using server reflection or .proto files.

  • Code snippets

    Generate code in 10 languages: cURL, Python, JavaScript fetch, Node Axios, Go, HTTPie, PHP, Java OkHttp, C# and Rust.

  • Organised your way

    Collections, folders, environments, globals and collection variables. History, saved response examples and request docs.

  • Local-first

    Local workspaces need no account and are stored only on your computer. Signing in, sharing and sync use the Floki server.

Bring what you already have

Import from the formats your team already uses, then export collections back out as Postman v2.1.

Import

  • Postman collections v2.0 / v2.1
  • Postman environments
  • cURL
  • OpenAPI 3
  • Swagger 2 (JSON / YAML)
  • RAML 1.0
  • WSDL

Protocols

  • REST
  • GraphQL
  • WebSocket
  • Socket.IO

Share when you want to

Sign in with email and password or Google, create team workspaces and invite people. Changes sync automatically.

  • Roles you control. Invite people as Admin, Editor or Viewer.
  • Self-host the sync server. It runs on PostgreSQL, so your team's data stays on your infrastructure.
  • Optional. Local workspaces stay on your computer; only workspaces you share are synced to the server.
