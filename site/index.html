The API client that isn't a browser.

Floki is a native desktop app, written in Rust and drawn on your GPU. It imports your Postman collections and runs their scripts, streams AI responses as they arrive, and works without an account.

Download Floki Compare with Postman

Free for Linux and Windows.

A macOS build is on the way. Meanwhile, the Linux and Windows builds are below.

New in 0.4

The biggest release so far: scripts, a runner, a command line and more ways to connect.

  • Scripts and tests

    Pre-request and post-response scripts on requests, folders and collections, with a simple test and expect API. Most Postman pm.* scripts run as they are, including ones that use pm.sendRequest and crypto-js.

  • Collection runner

    Run a collection or folder with iterations, delays and a CSV or JSON data file. Jump between requests with setNextRequest.

  • Command line for CI

    floki-cli run collection.json prints every test and exits non-zero on failure. One file to download, no Node.js, no account.

  • Server-sent events

    Event streams show up live. AI responses from OpenAI, Anthropic and Gemini style APIs are joined into readable Markdown, with thinking and token counts.

  • MQTT and Socket.IO events

    Connect to MQTT brokers, subscribe and publish with QoS and retain. Choose which Socket.IO events to listen to.

  • More sign-in methods

    OAuth 2.0 authorization code with PKCE through your browser, JWT Bearer, OAuth 1.0, Hawk and NTLM.

  • Cookies, preview and search

    A cookie jar that behaves like a browser's, HTML and image previews, and Ctrl+K to search everything in your workspace.

Built for how you test APIs today

Tests that read like tests

Write checks in plain JavaScript with test and expect, or keep the pm.test scripts you already have; most run without changes. Results show in a Tests tab next to the response, and logs in a Console tab.

  • Save tokens and IDs into environments for the next request
  • Sign requests with crypto-js in a pre-request script
  • Async tests, top-level await and pm.sendRequest
// Post-response script
test("returns the new user", () => {
  expect(res.status).toBe(201);
  expect(res.json()).toHaveProperty("id");
});
env.set("userId", res.json().id);

// Postman-style scripts work too
pm.test("Status code is 201", () => {
  pm.response.to.have.status(201);
});

The same run on your laptop and in CI

The collection runner sends every request in order, with your data file and scripts. floki-cli does the same in a pipeline and fails the build when a test fails.

  • Works with collections exported from Floki or Postman
  • Environment and globals files, JSON reports
  • A single binary for Linux and Windows
$ floki-cli run api.json -e staging.json -d users.csv

Share when you want to

Sign in to share workspaces with your team, on the Floki server or on a server you run yourself. Changes sync on their own.

  • Roles you controlInvite people to a workspace by email as Admin, Editor or Viewer, or add them to a team so they can open its workspaces.
  • Run your own sync serverThe Floki sync server is a single program backed by PostgreSQL. Run it with Docker Compose, which also sets up HTTPS for your domain, or as a systemd service behind nginx. Each release includes a ready-to-run Linux build. Server setup guide.
  • Connect the app to itIn Floki, choose Sign in, then "Use a self-hosted server", and enter your server's address. Accounts, teams and shared workspaces then live only on your server. Sign-in is by email and password; Google sign-in works when you add your own Google credentials to the server.
  • Private by defaultLocal workspaces never leave your computer. History, cookies and settings stay local even in shared workspaces, and Floki has no telemetry.

Download Floki

The latest release for Linux and Windows.

macOS

Floki-macos-universal.dmg

Download for macOS

For Apple silicon and Intel Macs, macOS 11 or later. Open the .dmg and drag Floki into Applications.

The app isn't notarized by Apple yet, so the first time you open it macOS says it can't check it. Open System Settings, then Privacy & Security, and click Open Anyway next to the message about Floki. You only do this once.

Windows

Floki-windows-x64-setup.exe

Download for Windows

Run the installer. Floki is added to the Start menu, and floki-cli is installed next to it.

Linux

Floki-linux-x64.deb

Download for Linux

Double-click to install on Ubuntu or Debian. On other distributions, download the .tar.gz and run:

tar -xzf Floki-linux-x64.tar.gz && ./Floki/install.sh

For CI, download just the command-line runner: floki-cli for Linux or floki-cli for Windows or floki-cli for macOS. All releases.
